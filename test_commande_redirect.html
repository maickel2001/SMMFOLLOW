🧪 Test Redirection Commande - BoostSocial

📋 Objectif du Test

Vérifier que la création de commande redirige automatiquement vers la page de paiement, et que l'upload de preuve fonctionne sur mobile.

🚀 Test de Création de Commande

Testez la création d'une commande et vérifiez la redirection automatique :

📝 Créer une Commande 🔧 Test des Permissions

1Créer une commande

Ouvrez commander.php et remplissez le formulaire avec des données valides

2Vérifier la redirection

Après soumission, vous devriez être automatiquement redirigé vers paiement.php?order_id=X

3Vérifier l'URL

L'URL doit contenir un order_id valide et afficher les détails de la commande

📱 Test Upload Mobile

Testez l'upload de preuve de paiement sur mobile :

💳 Test Paiement (ID=1) 🖼️ Test Upload Simple

⚠️ Important pour le Test Mobile

  • Utilisez un vrai appareil mobile ou activez l'inspecteur mobile dans Chrome DevTools
  • Testez les deux boutons : "Sélectionner un fichier" et "Prendre une photo"
  • Vérifiez que l'appareil photo s'ouvre sur mobile
  • Testez la galerie d'images pour sélectionner des captures d'écran existantes

1Test sur Mobile

Ouvrez paiement.php sur un appareil mobile ou simulez le mobile dans le navigateur

2Test Appareil Photo

Appuyez sur "Prendre une photo" - l'appareil photo doit s'ouvrir

3Test Galerie

Appuyez sur "Sélectionner un fichier" - la galerie doit s'ouvrir

4Vérifier l'Aperçu

Après sélection, l'aperçu de l'image doit s'afficher correctement

🔍 Points de Vérification

✅ Ce qui doit fonctionner

  • Redirection automatique après création de commande
  • URL avec order_id valide
  • Boutons d'upload visibles et cliquables sur mobile
  • Ouverture de l'appareil photo sur mobile
  • Ouverture de la galerie d'images
  • Aperçu de l'image après sélection
  • Bouton "Envoyer la Preuve" activé après sélection

⚠️ Problèmes potentiels

  • Redirection qui ne fonctionne pas
  • Boutons d'upload non cliquables sur mobile
  • Appareil photo qui ne s'ouvre pas
  • Galerie qui ne s'ouvre pas
  • Aperçu d'image qui ne s'affiche pas
  • Erreurs JavaScript dans la console

📱 Simulation Mobile dans Chrome

  1. Ouvrez Chrome DevTools (F12)
  2. Cliquez sur l'icône "Toggle device toolbar" (📱)
  3. Sélectionnez un appareil mobile (ex: iPhone 12)
  4. Testez les fonctionnalités d'upload
  5. Vérifiez que les boutons sont bien visibles et cliquables

📞 Support

Si vous rencontrez des problèmes :

  • Vérifiez la console du navigateur pour les erreurs JavaScript
  • Vérifiez les logs PHP dans error_log
  • Testez sur un vrai appareil mobile
  • Vérifiez les permissions du dossier uploads/
